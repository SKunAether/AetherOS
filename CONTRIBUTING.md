# Contributing to AetherOS Guardian

Thank you for considering contributing to AetherOS Guardian! We appreciate your time and effort.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs

Before creating a bug report, please check existing issues to avoid duplicates. When you create a bug report, include:

- A clear and descriptive title
- Steps to reproduce the issue
- Expected behavior and what actually happened
- Screenshots or code snippets if applicable
- Your environment (Windows version, .NET version, etc.)

### Suggesting Enhancements

We welcome feature suggestions. Please provide:

- A clear and descriptive title
- A detailed description of the suggested feature and its use case
- Any potential implementation details you've considered

### Pull Requests

1. Fork the repository and create your branch from `main`.
2. Follow the existing coding style (naming conventions, file structure, etc.).
3. Write clear commit messages that describe the purpose of your changes.
4. Test your changes thoroughly before submitting.
5. Ensure the build passes (CI will run automatically on your PR).
6. Submit a Pull Request to the `main` branch.

## Development Setup

1. Ensure prerequisites are installed: .NET 8 SDK, PowerShell, Windows 10/11.
2. Clone the repository.
3. Open the solution in Visual Studio or VS Code.
4. Build and run using `dotnet run`.
