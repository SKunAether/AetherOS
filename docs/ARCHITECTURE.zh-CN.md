# AetherOS 2.0 架构说明

## 概述

AetherOS 2.0 是基于 **Rust + Tauri + React + TypeScript + TailwindCSS** 构建的模块化
Windows 系统优化与管理平台。采用经典分层架构，自上而下职责单向依赖，内层不依赖外层。

```
┌──────────────────────────────────────────────────────┐
│                    React UI 层                        │
│   仪表盘 / 功能页面 / 组件 / 路由                     │
└──────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────┐
│                 Tauri IPC 桥接层                      │
│   命令调用 / 事件订阅 / 数据序列化                    │
└──────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────┐
│                命令与服务层                           │
│   Command 入口 / 服务编排                            │
└──────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────┐
│              能力运行时层                             │
│   Provider 注册 / 生命周期 / 插件加载 / 事件总线      │
└──────────────────────────────────────────────────────┘
┌──────────┬──────────┬──────────┬─────────────────────┐
│ 清理     │ 优化     │ 监控     │ 恢复                │
│ Provider │ Provider │ Provider │ Provider            │
└──────────┴──────────┴──────────┴─────────────────────┘
┌──────────────────────────────────────────────────────┐
│               系统引擎层                              │
│   Windows API 封装（注册表/进程/服务/文件/硬件）      │
└──────────────────────────────────────────────────────┘
```

## 设计原则

- **Capability Provider 模型**：所有系统能力以标准化 `CapabilityProvider` trait 提供，
  统一抽象、能力声明、统一调度、插件扩展。
- **分层隔离**：React UI 仅通过 Tauri IPC 与 Rust 通信；Provider 不直接调用 Windows API
  （平台调用全部收敛于 `aether-system`），便于未来 macOS/Linux 跨平台适配。
- **前后端分离**：IPC 调用统一封装于前端 `api/` 层并用 TanStack Query 缓存，状态由 Zustand 管理。
- **Feature-Sliced 前端**：按业务功能组织代码，而非按文件类型。

## 模块

| Crate / 包 | 职责 |
|---|---|
| `aether-core` | 领域模型、`CapabilityProvider` trait、错误、事件。无平台依赖。 |
| `aether-runtime` | Provider 注册中心、任务调度器、插件加载器、事件总线。 |
| `aether-system` | Windows API 封装：注册表、进程、服务、文件系统、硬件信息。 |
| `aether-cleaner` | 清理能力：临时文件、缓存、日志、回收站、注册表垃圾。 |
| `aether-optimizer` | 优化能力：电源计划、启动项、服务、网络、视觉效果。 |
| `aether-monitor` | CPU/内存/磁盘/网络实时监控与健康评分。 |
| `aether-recovery` | 还原点、配置备份恢复、操作回滚。 |
| `aether-plugin-sdk` | 第三方插件开发 SDK。 |
| `apps/desktop` | Tauri 2 桌面壳（Rust）+ React 前端。 |

## 数据流

1. React 组件调用 `api/` 封装函数 → Tauri `invoke`。
2. Tauri 命令分发到能力运行时或直接调用 Provider。
3. Provider 通过 `aether-system` 服务执行实际系统操作。
4. 长任务通过事件总线发布进度 → Tauri 事件 → React 监听器。

## 迁移说明

v1 代码库（C#/WPF，位于 `src/`）保留为历史参考。旧版业务逻辑与规则表
（扫描/清理/电源计划/历史记录）已移植到新的 Rust Provider；
插件体系从声明式 `plugin.json` 清单升级为真正的 `CapabilityProvider` 实现。
