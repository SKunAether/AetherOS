# Security Policy

## Supported Versions

We provide security updates only for the latest release. Older versions are not actively maintained.

| Version | Supported |
| :--- | :--- |
| 2.2.x | ✅ |
| < 2.2.0 | ❌ |

## Reporting a Vulnerability

If you discover a vulnerability, please do **not** create a public issue. Instead, email the maintainer:

**2820241167@qq.com**

Please include:

- Type of vulnerability (e.g., privilege escalation, data leak)
- Steps to reproduce
- Potential impact
- Any suggested mitigations

### What to Expect

- **Acknowledgment**: You will receive acknowledgment within 48 hours.
- **Updates**: We will keep you informed of progress.
- **Disclosure**: After the vulnerability is fixed, we will publicly acknowledge your responsible disclosure (unless you prefer to remain anonymous).

## Security Best Practices for Users

- **Download from Official Sources**: Only download from our [GitHub Releases](https://github.com/SKunAether/AetherOS/releases) page.
- **Verify Checksums**: Always verify the SHA-256 checksum of the downloaded package.
- **Run with Minimum Required Privileges**: Basic functionality does not require administrator rights.
- **Keep Updated**: Regularly update to the latest version for security patches.
